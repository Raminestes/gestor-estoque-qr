# Gestor de Estoque com QR 📦📱

Aplicativo para gerenciamento de estoque com integração de leitura de QR Code para produtos.

---

## 📍 Sobre o Projeto

Este projeto permite:
- Cadastrar produtos no estoque
- Ler códigos QR para identificar produtos
- Atualizar quantidade de itens rapidamente
- Interface intuitiva para uso em dispositivos móveis

---

## 🛠️ Tecnologias Utilizadas

- JavaScript / TypeScript  
- React Native (Expo)  
- Leitor de QR Code (`expo-barcode-scanner`)  
- Package.json para dependências  

---

## 🚀 Como rodar

```bash
git clone https://github.com/Raminestes/gestor-estoque-qr.git
cd gestor-estoque-qr
npm install
npx expo start

```

Este projeto foi desenvolvido como parte de atividades acadêmicas com foco em aprendizado prático sobre desenvolvimento mobile, integração com hardware (câmera) e persistência de dados.
